# iintoo Registration Page

Web Core, Lesson 4.5

Responsive layout of an investor registration form, built with HTML and CSS.

**Live page:** https://github.com/Erkhemee0908/landing-page-web-core-4.7/deployments/github-pages

**Task:** [CSS Task](https://github.com/Habsida-Projects/css-task-english)

## Features

- Responsive layout for mobile, tablet and desktop
- Custom styled inputs, radio buttons and checkbox
- Hover and keyboard focus effects with smooth transitions
- Semantic HTML with fieldset and legend for the radio group

## Built with

- HTML5
- CSS3
